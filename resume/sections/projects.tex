\subsection{{Small Subway --- \href{https://smallsubway.calnight.in/gale/}{smallsubway.calnight.in/gale} \hfill Typescript, HTML/CSS, GitHub Actions}}
\begin{zitemize}
\item Metro simulation; presents the user with stations which they must connect to enable passengers to reach their destinations
\item Utilizes a breadth-first search of the station graph to route passengers and trigonometric rendering algorithms to display  trains
\end{zitemize}

\subsection{{Voxel Procedural Terrain Generation --- \href{https://github.com/CalNightingale/voxel-terrain-gen}{github.com/CalNightingale/voxel-terrain-gen} \hfill C++, OpenGL}}
\begin{zitemize}
\item Implemented basic voxel rendering using OpenGL pipeline in addition to some rendering performance optimizations 
\item Implemented biome shape and type assignment using Voronoi Diagrams and Perlin noise
\end{zitemize}

\subsection{{2D Game Engine --- \href{https://github.com/CalNightingale/Hamboning}{github.com/CalNightingale/Hamboning} \hfill Java, JavaFX}}
\begin{zitemize}
\item Created a 2D game engine similar in structure to Unity; supporting sound, user input, sprites, behavior trees, and more
\item Wrote a simple game, Hamboning, based on The Regular Show to showcase engine features
\end{zitemize}
